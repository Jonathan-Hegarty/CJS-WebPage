# CJS Solutions website

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Preview locally

1. Extract the ZIP (if using the packaged download).
2. Open `index.html` in a modern web browser.
3. For the best local development experience, serve this folder with a simple static server (for example, VS Code Live Server).

## Files

- `index.html` — page content and five main sections: Home, About Us, Projects, Reviews and Contact Us.
- `styles.css` — layout, brand colours, responsive breakpoints and visual styling.
- `script.js` — mobile navigation, active section highlighting, reveal effects, project filters and contact form validation.
- `assets/cjs-logo.png` — your supplied logo, cropped to remove excess white space.
- `assets/favicon.svg` — simple browser tab icon using the CJS brand colours.

## Before publishing

- **Contact form:** open `script.js` and replace `ADD-YOUR-EMAIL-HERE` with the inbox you want enquiries sent to. The form validates the fields and opens a pre-filled email draft using the visitor's email app. It does not send or store messages on a server. For a fully hosted form, connect a form service or your own backend.
- **Projects:** the three cards are clearly labelled illustrative concepts, not completed client work. Replace them with genuine projects when you have them.
- **Reviews:** the reviews section is deliberately written as a transparent placeholder. Add genuine client feedback only after you have permission to publish it.
- **Company details:** add your real business email, social links, address and any legal/privacy information you need before launch.

The website uses Google Fonts (DM Sans and Manrope) when internet access is available; it falls back to system sans-serif fonts otherwise.
